## 工作流

```text
新剪藏进入 Clippings/
  → 初筛：对照兴趣基准定级 + 完整度检查（基准见 8-知识库管理/项目记忆 §1.1）
  → 图片分级：key级/图片即内容的原文 → 图片下载到 attachments/ 本地化备份；
    其余图片转文字标注（防图床失效）
  → 生成处理卡片（8-知识库管理/Clippings处理/，编号顺延）
  → 原文迁出到对应技能分类，卡片 source_path 同步更新
  → 所在分支的 汇总.md 增量更新（新篇评级 + 框架修订）
  → 人工确认后转化或保留摘要
```

兴趣基准速查：数据/BI/AI＝本职核心（S/A）；经营＝工作相关 S/A、泛观察 B；工具技巧＝B 用时查；新兴事物＝B/C 浏览型。

规则：原文内容只读不改，只迁位置；迁移后卡片与分组 README 的链接同步更新。
