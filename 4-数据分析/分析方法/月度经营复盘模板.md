# 月度经营复盘模板

> **定位**：跨境电商业务月度复盘的固定框架，把"看报表"升级为"事实—原因—行动"闭环。
> **适用范围**：月度周期；单平台或全渠道均可，口径需先按下文《口径清单》确定。
> **来源**：整合知识卡片 [[8-知识库管理/Clippings处理/15-经营分析四个问题]]（三段式骨架）、[[8-知识库管理/Clippings处理/11-财务分析三套底层模型]]（三套底层模型）、[[8-知识库管理/Clippings处理/13-毛利率三层九格拆解]]（毛利下钻）、[[8-知识库管理/Clippings处理/14-三张财务报表分析顺序]]（三表联动），并与 [[5-正式知识资产/数据分析/P&L利润链路总览]] 的口径对齐。
> **状态**：draft——未经用户确认前不得作为正式复盘标准。

## 使用规则

1. 每次复盘只回答三个问题：**发生了什么（事实）→ 为什么发生（原因）→ 下一步谁做什么（行动）**。
2. 每条结论必须带数据来源和口径；没有证据的数字不进入事实层。
3. 行动必须落到"负责人 + 截止日 + 预期收益 + 回测指标"，写不出回测指标的行动不立项。
4. 找到"最值得解释的 2-3 个问题"深挖，不追求覆盖所有指标。

## 第一段：事实层（发生了什么）

按固定顺序核对当月结果与上月/去年同期对比，只记录变化和幅度，不做解释：

| 层次 | 核对项 | 说明 |
| --- | --- | --- |
| 收入 | GMV、净销售、退款、折让 | 平台/站点/渠道分组 |
| 毛利 | 毛利额、毛利率 | 毛利口径见《口径清单》第 1 条 |
| 费用 | 平台费、广告、履约、仓储、期间费用 | 费率与绝对额并看 |
| 利润 | 贡献利润、经营利润 | 区分供货口径与终端口径（VC） |
| 现金 | 经营现金流、平台应收、库存占用 | 利润≠现金，必须并看 |

事实层产出：一张指标变化表 + 圈出"最值得解释的 2-3 个异常"。

## 第二段：原因层（为什么发生）

对事实层圈出的每个异常，依次用三套底层模型定位层次，再用毛利九格下钻：

**Step 1 三套底层模型定位**（哪一层出的问题）：

1. **利润分析**：收入、成本、费用如何形成利润——变化发生在收入端还是成本费用端？
2. **结构分析**：按产品 / 客户 / 区域 / 渠道拆解总量——是整体变化还是个别结构拖动？
3. **驱动分析**：销量、价格、单位成本、费用率——具体驱动因素各贡献多少？

**Step 2 毛利率三层九格下钻**（毛利类异常专用）：

| 层 | 下钻格 | 连接能力 | 常见跨境诱因 |
| --- | --- | --- | --- |
| 价格 | 折扣/实收价、产品结构、客户/渠道结构 | 定价能力 | 促销加深、低价 SKU 占比上升、大客户议价 |
| 成本 | 采购价、单耗、损耗；固定费用/产量 | 效率能力 | 采购涨价、头程/关税波动、仓储费率 |
| 结构 | 产品组合、渠道组合、业务组合 | 组合管理 | 低毛利新业务放量、渠道权重变化 |

**Step 3 三表联动校验**（利润解释是否成立）：

- 利润改善是否带来现金改善？核对经营现金流与利润的匹配度。
- 三个必查项：平台应收与结算周期、库存（在途/海外仓/本地）周转、应付与预付。
- 应收、存货、借款出现异动时，利润结论必须补充资金占用解释。

原因层产出：每个异常 1-3 条"事实→原因"链，每条标注证据（数据表/口径）与置信度。

## 第三段：行动层（下一步做什么）

| 字段 | 要求 |
| --- | --- |
| 行动描述 | 一个动作，可执行、可验证 |
| 负责人 / 截止日 | 具体到人和日期 |
| 预期收益 | 量化（金额/比率），说明作用于哪一层哪个驱动因素 |
| 回测指标 | 下次复盘核对什么数字，判定行动是否生效 |

行动层产出：不超过 5 条行动项；超出说明原因层没有收敛，回炉重拆。

## 口径清单（复盘前必须确认）

1. 毛利口径：是否含平台费、广告、履约、退款、税费、汇兑——按 [[5-正式知识资产/数据分析/P&L利润链路总览]] 的定义执行，不得临场改口径。
2. 供货与终端口径分离：VC PO/DF/DI 是供货结构，terminal/endpos 是终端销售，不混算。
3. 广告促销费用按 `渠道 + 日期 + ASIN` 聚合后进利润表，避免金额放大。
4. 库存成本结转方法与在途/海外仓货权列报口径，需与实际业务一致。
5. 现金流折算与汇率处理方式固定，不逐月更换。

## 验收标准

- [ ] 事实层每项变化都有数据来源和口径标注
- [ ] 原因层每个异常至少一条完整的"事实→原因→证据"链
- [ ] 毛利类异常完成三层九格下钻，未笼统归因"成本上涨"
- [ ] 利润结论附带现金匹配校验（应收/库存/结算周期三项必查）
- [ ] 行动层 ≤5 条且每条有负责人、截止日、预期收益、回测指标
- [ ] 全程未修改口径；如需修改，先走 [[知识库管理项目说明]] §11.2 业务规则变更流程

## 限制与待确认项（draft 阶段）

- 指标分层以利润/毛利为主，库存健康度（滞销/断货）与广告效率（ACOS/ROAS）专题未纳入——是否扩入由使用场景决定。
- "三套底层模型"原文含 FineBI 产品推广内容，已剥离，仅保留方法论框架。
- 毛利率九格原文末层疑似笔误（"价格、成本、价格"），本模板按"价格/成本/结构"整合，待原文核对。
- 平台应收、VAT、在途货权的列报口径需与实际项目数据核对后方可用于正式复盘。

## 复盘记录归档约定

每次执行复盘时复制本模板为 `YYYY-MM 经营复盘` 存入当期目录（建议 `4-数据分析/` 下按月归档，结构待实践后确定），复盘记录不回写本模板。
