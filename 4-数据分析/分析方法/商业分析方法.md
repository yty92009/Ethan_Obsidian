# 商业分析

> 返回 [[知识库首页]] ｜ 平行专题：[[4-数据分析/分析方法/经营分析方法|经营分析]]

> 商业分析关注“市场和业务应该往哪里走”：理解外部环境、客户、竞争、产品、渠道和商业模式，并把分析转化为增长、资源配置和战略选择。

## 一、核心问题

1. 市场机会在哪里？
2. 客户为什么购买、流失或转化？
3. 竞争对手的产品、价格、渠道和能力如何？
4. 哪些产品、市场和渠道值得投入？
5. 当前增长是规模增长、利润增长，还是现金和能力的健康增长？
6. 下一步应该选择什么、放弃什么、验证什么？

## 二、商业分析框架

```mermaid
flowchart LR
    A[商业目标] --> B[市场与竞争]
    B --> C[客户与需求]
    C --> D[产品与价值主张]
    D --> E[渠道与增长]
    E --> F[收入/成本/利润/现金]
    F --> G[资源配置与行动]
    G --> H[结果复盘]
    H --> B
```

### 1. 市场与竞争

- 市场规模、增长和细分
- 站点、国家、平台和品类机会
- 竞品池、价格、促销、Listing、评价、排名和流量
- 竞争优势、进入壁垒和风险

### 2. 客户与需求

- 客户是谁、需求是什么
- 客户获取、转化、复购和流失
- 客户价值、价格敏感度和渠道差异

### 3. 产品与组合

- 产品定位和价值主张
- SKU 组合、产品生命周期和产品结构
- 高毛利/低毛利、引流款/利润款和战略投入

### 4. 经济模型

- 净销售、贡献利润和经营利润
- 价格、成本、结构、费用和现金
- 盈亏平衡、安全边际和敏感性

### 5. 决策与资源配置

- 投入什么、停止什么、继续验证什么
- 负责人、时间、预算、预期收益和退出条件
- 用实际结果反哺策略和模型

## 四、商业分析与经营分析的边界

| 维度 | 商业分析 | 经营分析 |
| --- | --- | --- |
| 核心问题 | 方向和选择是否正确 | 结果和过程为什么变化 |
| 时间尺度 | 中长期、阶段性 | 日/周/月、持续经营 |
| 关注对象 | 市场、客户、竞争、产品、渠道 | 收入、成本、利润、库存、现金、效率 |
| 典型输出 | 市场机会、竞品策略、产品/渠道选择、投资建议 | 经营复盘、异常归因、行动清单、责任追踪 |
| 常见方法 | 市场细分、竞品分析、客户分析、商业模式、情景测算 | 利润桥、结构拆解、毛利分析、预算差异、营运指标 |

## 五、最小实践任务

选择一个 Amazon 站点或品类，完成一页商业分析：

- 市场和竞品现状
- 客户/需求假设
- 产品和价格位置
- 渠道与增长机会
- 单位经济模型
- 主要风险
- 建议继续投入、停止或验证的事项

验收标准：

- 每个判断有来源、假设或数据证据。
- 能区分事实、推断和建议。
- 至少提出一个可在两周内验证的行动。
