# 面试储备知识库

这个知识库用于把过往工作经历、项目经历、技术栈和面试表达素材沉淀下来。目标不是简单记录简历内容，而是把真实经历整理成面试时能稳定表达的答案。

## 使用方式

优先按面试流程使用：

1. 如果是隔了一段时间重新打开，或迁移到新账号 / 新电脑 / 新工具，先看 `项目记忆.md`。
2. 再看 `00_个人定位/个人定位与核心优势.md`，明确自己的候选人标签。
3. 面试前准备 `06_面试流程/01_自我介绍.md`，根据面试场景选择 30 秒、1 分钟或 2 分钟版本。
4. 业务面重点看 `02_重点项目/`，每个项目都按“背景、问题、行动、结果、复盘”准备。
4a. 工作经历按 `01_工作经历/` 档案准备：iPower 为主讲段；饿了么（平台三端经营）、智联招聘（B2B 销售运营）按岗位侧重选用——不确定面试官对哪段感兴趣时，三段都要能讲。
5. HR 面重点看 `06_面试流程/02_HR必问问题.md` 和 `06_面试流程/06_容易踩坑的问题.md`。
6. 业务负责人或老板面重点看 `06_面试流程/04_业务负责人模拟问答.md`。
7. 技术负责人或数据负责人面重点看 `06_面试流程/05_技术负责人模拟问答.md`。
8. 每次真实面试结束后，把复盘补充到 `07_面试复盘/`，并把可复用问题沉淀到 `06_面试流程/`。
9. 每次看到合适岗位或发来招聘简章后，归档到 `08_招聘简章分析/`，用于长期总结岗位匹配度、个人优劣势和市场需求变化。
10. 如果是具体公司面试前准备，优先看对应的专项准备包，例如 `06_面试流程/09_神策数据_数据分析师J11333_面试准备包.md`、`06_面试流程/10_传音控股_高级数据分析经理_面试准备包.md`。

## 长期维护入口

`项目记忆.md` 是这个知识库的长期上下文文件。后续任何人或 AI 助手接手维护时，都应该先读这个文件，再读 README 和具体业务文件。

## 面试表达原则

- 先讲业务问题，再讲数据和工具。
- 先讲自己负责的部分，再讲团队协作。
- 先讲结果，再补过程。
- 不把 BI 说成“做报表”，要说成“经营管理体系建设”。
- 不把自动化说成“写脚本”，要说成“降本、提效、控风险”。
- 性格内向不要主动暴露为短板，可以表达为“习惯提前准备，表达偏结构化，做事比较稳”。
- 看招聘简章时，不只判断能不能投，还要沉淀市场正在要什么能力，以及你的简历和话术要怎么调整。
- 每次面试沟通后，不只评价表现，还要沉淀成复盘、问答模板和表达训练。
