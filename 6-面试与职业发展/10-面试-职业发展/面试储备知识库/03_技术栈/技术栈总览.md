# 技术栈总览

## BI 与可视化

- Power BI
- Tableau
- Quick BI
- 帆软
- Smart BI
- AntV
- ECharts

表达重点：

> 我使用 BI 工具的重点不是单张报表美化，而是围绕业务主题搭建可持续维护的分析体系，包括指标口径、数据模型、权限、下钻维度和异常监控。

## 数据库与数据处理

- SQL
- MySQL
- SQL Server
- PostgreSQL
- Hive
- Python 数据获取、清洗、整合、入库

表达重点：

> 我比较熟悉从源数据到分析数据集的处理过程，能用 SQL 和 Python 完成清洗、映射、汇总、入库和报表支撑，不只停留在前端展示。

## 自动化与 AI 工具

- Python
- 影刀 RPA
- n8n
- Claude Code
- Codex

表达重点：

> 对于规则清晰、重复性高、人工容易遗漏的流程，我会优先考虑自动化，比如后台数据下载、账单核对、差评抓取、竞品价格监控、批量数据整理等。

AI 工具表达重点：

> 我会把 AI 当成数据分析和自动化工作的效率工具，用于辅助 SQL / Python 思路、数据清洗、文档整理、指标口径梳理、经营分析总结和自动化流程设计。但涉及业务结论时，仍然要回到数据源、业务口径和校验逻辑，不能直接把 AI 输出当事实。

### Agent 一句话解释

> Agent 是能围绕目标自主拆解任务、调用工具、执行步骤并反馈结果的 AI 助手。

适合面试补充：

> 普通 AI 更像问答工具，Agent 更像能连续办事的助手。比如让它分析经营数据，它可以读取文件、检查字段、生成代码或 SQL、汇总异常，再整理成报告。

### AI 相关常见面试问题

| 问题 | 建议回答方向 |
|---|---|
| 你怎么看 AI 对数据分析岗位的影响？ | AI 提高效率，但业务定义、口径统一、结果判断和推动落地仍然需要人 |
| 你实际怎么用 AI？ | 辅助 SQL、Python、数据清洗、文档整理、指标口径、自动化流程和知识库沉淀 |
| AI 能替代数据分析师吗？ | 可替代重复劳动，不能替代业务理解、责任判断和跨部门协调 |
| 使用 AI 有什么风险？ | 数据安全、权限、幻觉、口径错误、结果未经校验 |
| AI 在跨境电商里的场景？ | 评论分析、差评归因、广告关键词、竞品监控、自动化报表、库存预警解释 |

## 数据仓库与数据治理

常用表达：

> 我实际工作中会按 ODS、DWD、DWS、ADS 的思路组织数据。ODS 保留源数据，DWD 做清洗和标准化，DWS 做业务主题汇总，ADS 面向具体报表和经营分析。对中小型公司来说，不一定一开始就做很重的数据中台，但分层思路和口径管理一定要有。

## 技术表达注意事项

- 不要把工具列表背一遍。
- 每个工具都要能对应一个业务场景。
- 技术回答要尽量落到“解决了什么问题”。
- 如果面试官问技术深度，先讲项目中的真实用法，再补理论。
