# 招聘简章分析

这个模块用于长期保存你发来的招聘简章，并通过不同公司的 JD 反向总结：

- 当前市场在招什么样的数据 / BI / 经营分析岗位。
- 这些岗位普遍要求哪些业务经验、技术能力、管理能力和沟通能力。
- 你的经历和这些岗位的匹配点在哪里。
- 你的短板、风险点和需要补充的话术在哪里。
- 后续简历、自我介绍和项目表达应该如何调整。

## 目录结构

```text
08_招聘简章分析/
  00_招聘简章索引.md
  README.md

  01_原始JD/
    保存每一份招聘简章的文字版。

  02_岗位匹配分析/
    对每一份 JD 做匹配度、优势、短板、面试重点分析。

  03_市场需求总结/
    汇总多份 JD 后，观察市场对跨境电商 BI / 数据负责人的真实要求。

  04_个人优劣势复盘/
    动态沉淀你的优势、短板、补强方向和话术策略。
```

## 新增 JD 的维护方式

每次你发来新的招聘简章时，建议至少新增或更新三类内容：

1. 在 `01_原始JD/` 中保存原始 JD 文字版。
2. 在 `02_岗位匹配分析/` 中生成一份岗位匹配分析。
3. 更新 `00_招聘简章索引.md`、`03_市场需求总结/跨境电商BI岗位市场需求观察.md` 和 `04_个人优劣势复盘/个人优劣势动态总结.md`。

## 分析原则

- 不为了投递而强行说“完全匹配”。
- 明确区分“强匹配”“部分匹配”“需要补话术”“真实短板”。
- 对不确定的平台或工具经验，不编造，使用“可迁移经验”表达。
- 市场趋势必须基于多份 JD 累积，不从单个岗位过度下结论。
- 每次分析都要能反哺简历、自我介绍、项目深挖和 HR 问答。
