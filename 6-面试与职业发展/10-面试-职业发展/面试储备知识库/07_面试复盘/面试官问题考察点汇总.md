## 当前已识别的高频能力模型

### 1. 业务问题发现能力

典型问法：

- 你主动发现过哪些业务问题？
- 你怎么判断一个业务问题值得分析？
- 你怎么从数据里发现异常？

应该准备的素材：

- 库存数据不准案例。
- 广告效率异常案例。
- 费用 / 利润异常案例。
- 自动化对账发现索赔机会案例。

### 2. 数据治理和口径统一能力

典型问法：

- 数据混乱时你第一件事做什么？
- 多个系统数据不一致怎么办？
- 怎么保证报表数据准确？

应该准备的素材：

- 数据采集、清洗、主数据、指标口径、数仓分层的 7 步框架。
- SKU / ASIN / 店铺 / 平台 / 供应商 mapping 案例。
- 销售、财务、平台、库存数据对账方法。

### 3. 影响业务决策的能力

典型问法：

- 有没有用数据改变业务判断的案例？
- 你的分析结果怎么推动业务动作？
- 分析报告如何落地？

应该准备的素材：

- SKU 利润和库存决策案例。
- 补贴 / 费用投放效率案例。
- 库存预警、Buy Box、竞品价格、销量下滑预警案例。

### 4. 工程化和技术落地能力

典型问法：

- 大数据量怎么查？
- BI 报表慢怎么优化？
- 数据仓库怎么分层？
- T+1 数据怎么保证可信？

应该准备的素材：

- 1000 万订单近 30 天 GMV 查询方案。
- Power BI 性能优化方案。
- ODS / DIM / DWD / DWS / ADS 分层方案。
- 数据质量校验和异常监控方案。

## 当前训练优先级

1. 库存数据不准案例：补成 1 分钟 STAR 版本。
2. 多源数据不一致：练成 1 分钟结构化回答。
3. 1000 万订单 GMV：练成 1 分钟技术方案回答。
4. 数据混乱第一件事：和 BI 从 0 到 1 框架打通。
