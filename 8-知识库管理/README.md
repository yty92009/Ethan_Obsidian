## 扫描命令

建议将报告输出到 Vault 外部，避免报告被再次扫描：

```powershell
python .\8-知识库管理\scripts\obsidian_audit.py scan `
  --vault 'D:\Ethan\Ethan' `
  --out 'D:\Ethan\obsidian-audit-output'
```

脚本默认：

- 只读扫描，不移动、删除或覆盖 Vault 文件
- 排除 `.obsidian`、`.git`、`.trash`、虚拟环境、构建目录等
- Markdown 解析标题、frontmatter、标签和基础统计
- 图片、源码、Office、PDF、音视频只计数，不解析
- 生成 `scan_report.md/json` 和 `processing_queue.md/json`
- 队列中的 `needs_review` 始终为 `true`

## 处理原则

1. 先扫描，再由 AI 生成摘要和关联建议。
2. 不把外部资料直接当成个人经验或正式业务规则。
3. 涉及 P&L、财务风控、项目结果和个人经历的内容，人工确认后才能进入正式笔记。
4. 自动化写入、移动和删除暂不启用，作为后续独立阶段。
