# 99-收件箱

这里存放尚未完成知识处理的资料和 AI 处理结果。

> 网页剪藏的主收件箱是 `7-收藏资料/Clippings/`（剪藏器直接写入）；本目录用于手动投放的资料和中间状态。剪藏处理完成后**原文迁入对应技能分类**（1-数据／2-BI／3-AI／4-数据分析／6-面试与职业发展），处理卡片留在 `8-知识库管理/Clippings处理/`。

## 目录说明

- `待筛选/`：刚投放、尚未判断价值的资料
- `已筛选/`：已经判断主题和优先级，等待进一步总结
- `待实践/`：已经总结，但需要通过代码、项目或工作场景验证
- `待归档/`：暂时不值得深入，但保留作为参考

## 推荐流程

```text
剪藏 → 7-收藏资料/Clippings/（未处理收件箱）
  → AI 初筛 + 生成处理卡片（8-知识库管理/Clippings处理/）
  → 人工确认
  → 原文迁入对应技能分类 / 待实践 / 待归档
```

## 使用规则

- 不覆盖原始资料；处理结果使用新文件或报告保存。
- AI 生成内容必须标明来源和处理状态。
- 外部观点、教程示例和个人真实经验必须区分。
- 涉及财务口径、生产规则、项目结果和个人经历的内容，人工确认前不得写入正式笔记。
