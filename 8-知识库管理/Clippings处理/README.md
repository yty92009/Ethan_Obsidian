# Clippings 收藏资料处理结果

## 目的

本目录是剪藏处理的工作区：对 `7-收藏资料/Clippings/` 中的网页剪藏进行筛选、摘要、关联和行动化处理，生成处理卡片。**处理完成的原文按工作流迁入对应技能分类**（说明 §6 第八步），本目录保留卡片与批次记录。

## 处理原则

- 原文内容只读，不修改；处理完成后原文**迁移位置**（卡片 `source_path` 同步更新）。
- 每张卡片记录 `source_path` 与审核优先级（`review_priority: key / spot_check`）。
- 外部观点、宣传性数字、工具版本和业务规则均不直接视为已验证事实。
- `needs_human_review: true` 表示等待人工审核（仅 key 卡与 draft 资产）；`review_priority: spot_check` 的卡为 false，不进入批量审核，用时核对。
- 正文主要依赖图片、无法可靠读取的资料标记 `verification_status: incomplete_source`，只做占位卡，不强行总结。
